# Game locale

The application uses i18next and react-i18next. Vietnamese (`vi`) is the default and fallback locale. The persistent React shell owns its provider and instance, so navigation keeps the locale and server renders do not share mutable translation state.

## Source

`apps/game/src/application/i18n/locales/vi/` contains `common.ts`, `farm.ts`, `inventory.ts`, and `settings.ts`. Resources use TypeScript `as const`; the i18next module augmentation checks namespace and key names. `instance.ts` also works outside React when supplied explicitly to a runtime.

```tsx
const { t } = useTranslation('inventory');
<p>{t('detail', { name: item.label, count: item.count })}</p>
```

Use semantic keys, not Vietnamese sentences as keys. Keep complete sentences in resources and interpolate values. Business identifiers, saved progress and API payloads remain unchanged.

Shared UI accepts translated labels through props, for example `AudioSettingsPanel.labels`; it does not import the application locale.

## Adding a language

Add its namespace files under `locales/<language>/` and register them in `resources.ts`. Match the Vietnamese key structure. Translate all enabled screens before exposing a language selector. Use `i18n.changeLanguage(language)` to update React consumers; runtime-rendered text must refresh on `languageChanged` and remove that listener on cleanup. Persist a selected language through the user-settings contract when that feature is added.

## Current migration coverage

Migrated: application loading/error states, farm header/menu/plot actions/help/notifications, farm unit controls, batch care, inventory and audio settings.

Still Vietnamese inline: legacy world-map/character screens, some DOM UI helpers and runtime-rendered labels, developer tools, and shared UI default labels. These are not represented as a completed whole-game translation. Only Vietnamese is currently enabled.

Reference: [react-i18next provider](https://react.i18next.com/latest/i18nextprovider), [typed resources](https://www.i18next.com/overview/typescript).

# Pet shop and supplied pet expansion

Source artwork is retained in `docs/art/pet-shop/`. The room is assembled from individual WebP modules, never the reference screenshot. `assets.json` lists crop coordinates; export with `python3 tools/pet-shop/export-assets.py` (Pillow required). Walls, floors, doors, window, clock, pictures, cages, shelves, counter, stools, plants, bowls, water bottle and bed are individually reusable. The desk's book, computer and plant are separate layers; its clear tabletop is restored from its own source wood pixels. The employee is the existing female character preset, rendered independently behind the desk.

`center/pet-shop` uses the shared location/presence runtime. The shopping-street pet storefront enters it. The yellow marker in front of the counter opens the common shop UI with trial, purchase and equip actions. Normal pet price remains 80,000 coins. Only the first level is offered; no upgrade feature is introduced. Furniture is prepared for future room furnishing; furniture ownership/trading is not introduced here.

`pets.json` records row/frame coordinates from the supplied three-level pet sheet. `python3 tools/pet-shop/export-pets.py` creates only the eight new sprite families (ginger cat, puppy, deer, panda, pig, turtle, clownfish and songbird). Their metadata is tracked in character-core's `data/pets.json`. No existing animal sprites, IDs, palettes or ownership are replaced. Frames share a per-level canvas and foot anchor. Transparent halos and disconnected neighbouring fragments are removed; native sizes are 30/37/44 pixels high before padding. The exporter uses the existing pet palette without dithering. Clownfish and songbird hover via the existing flyer mechanism. Artwork is derived from supplied pixels; it is not newly AI-generated or claimed as user-approved.

The shop, character information and public profile share the circular character preview, including the equipped pet. The existing pet-following simulation is also used in location maps for local and remote players. Existing farm following is retained.

The four populated display cages are individual props cropped and silhouette-masked from the supplied reference room (`maskRects` in the manifest). Their pets retain the reference positions and proportions, without layering wearable pet sprites over cage frames. The empty cage module remains available for future furnishing. Room walls, floor, desk, employee and other furniture are still independently composed.

# Handheld shop

`center/held-shop` is entered through the existing handheld/gifts storefront on Shopping Street. It uses the shared location renderer, player presence, movement, header and return navigation. The separately rendered employee and front-counter yellow marker open the common shop modal (`accessories`, slot `held`). The shop has one direct tab; only the item list scrolls. Trial is local; purchase, price, ownership and equip validation use the existing server inventory commands. All eight additions cost the normal equipment price, 40,000 coins each. No furniture purchase or housing system is introduced here.

User-supplied originals are retained under `docs/art/held-shop/`. `assets.json` defines 28 reusable room props/tiles: floor, wall, door, sign, furniture, counter, desk accessories, shelves and populated merchandise displays. `python3 tools/held-shop/export-assets.py` (Pillow) exports lossless WebP modules. The clean counter wood is taken from the supplied counter itself; books, computer, plant and employee are independent scene objects. The room is composed from these modules, never a baked screenshot. Floor/front wall tiles use clean crops from the reference room.

`items.json` records eight item crops, native heights, grip positions and display angles. `python3 tools/held-shop/export-items.py` derives pixel sprites from the supplied atlas and writes only those managed metadata entries in character-core's `data/items.json`. Existing source artwork and palette symbols are preserved. Each new item has a fixed palette in its own group, 48 quantized source colors, no dithering; reserved Unicode palette symbols are stable across exports. Items attach at the existing near hand/grip anchor and point away from the face. The engine retains the shared grip overlay and mirrors both item and hand for the opposite direction. No AI-generated artwork is required for these additions.

New items: star wand, heart wand, moon wand, snow wand, sunflower wand, pink guitar, tennis racket and rose. They use the existing held slot, bag/equip lifecycle, thumbnails and fixed-camera circular preview. Art has been inspected at native/enlarged size in isolation, on male/female characters and in both directions; this is not user artwork approval or live browser UI verification. Standing and walking poses, crop bounds, storefront/exit/counter interactions, ownership rejection, repeat-purchase receipts and wallet charges have automated regression coverage in `tests/held-shop.test.ts`.
